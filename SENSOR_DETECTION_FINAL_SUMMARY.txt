## 🔍 SYSTEM OVERVIEW

### How It Works (4 Steps)

STEP 1: DEFINE SENSOR IDs
├─ Each sensor assigned unique identifier (0x01-0x05)
├─ Stored in sensor registry
└─ Used for validation

STEP 2: IMPLEMENT HANDSHAKE ROUTINE
├─ Send trigger/pulse to each sensor
├─ Wait for response (configurable timeout)
├─ Record sensor's ID or signature
└─ Log detection result

STEP 3: VALIDATE SENSOR PRESENCE
├─ Check if response matches known sensor ID
├─ Compare received data against expected signature
├─ Mark sensor as connected or missing
└─ Update status in registry

STEP 4: REPORT CONNECTED SENSORS
├─ Display which sensors are detected
├─ Show active sensor list
├─ Provide error messages for missing sensors
└─ Log results with timestamps

## 📊 DETECTION METHODS

### Digital Sensors (GPIO)
1. Send test pulse (HIGH → LOW)
2. Wait for response (100ms timeout)
3. Read pin state
4. Validate against signature

### Analog Sensors
1. Write test value
2. Wait for feedback
3. Read analog input
4. Check valid range

### I2C Sensors
1. Start I2C transmission
2. Send to device address
3. Check acknowledgment
4. Record device address

### Serial Sensors
1. Send query command
2. Wait for response (1 second timeout)
3. Parse response data
4. Verify sensor signature

## 🛠️ TROUBLESHOOTING

Problem:                    Solution:
─────────────────────────────────────────────────────────────
All sensors not detected    → Connect Arduino via USB
						   → Select COM port in app
						   → Click "Connect"

Some sensors missing        → Check wiring
						   → Verify pin numbers
						   → Test each sensor individually

Detection hangs/times out   → Check sensor power supply
						   → Verify sensor enable pin
						   → Reset Arduino

I2C sensors not found       → Check pull-up resistors (4.7kΩ)
						   → Verify SDA/SCL wiring
						   → Check device address
