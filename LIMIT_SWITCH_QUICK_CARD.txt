## TEST PROCEDURE (5 minutes)

1. **SETUP**
   ```
   ☐ Wires connected to Pin 4 + GND
   ☐ Arduino connected via USB
   ☐ WinUI app open
   ☐ COM port selected
   ☐ Connected (green indicator)
   ```

2. **START MONITOR**
   ```
   ☐ Driver Testing tab
   ☐ Select "7. Limit Switch Monitor"
   ☐ Click "▶ Start Monitor"
   ☐ See "🟢 OPEN (HIGH)" on display
   ```

3. **PRESS & RELEASE**
   ```
   ☐ Press switch → see "🔴 PRESSED (LOW)"
   ☐ Release → see "🟢 OPEN (HIGH)"
   ☐ Counter should increase to 1
   ☐ Event log should show timestamp
   ```

4. **REPEAT**
   ```
   ☐ Press 10 more times
   ☐ Counter should show: 1, 2, 3, 4, 5...
   ☐ Each press/release shows in event log
   ☐ No flickering - state should be stable
   ```

5. **VERIFY**
   ```
   ☐ Counter = 10? ✓
   ☐ All events logged? ✓
   ☐ Instant state changes? ✓
   ☐ No technical issues? ✓
   ```

## TROUBLESHOOTING IN 30 SECONDS

| Issue | Check | Fix |
|-------|-------|-----|
| No state change | Wire connections | Reseat wires at Pin 4 & GND |
| Stays HIGH always | Wires, switch | Press hard, check continuity |
| Stays LOW always | Stuck switch | Press/release vigorously |
| Flickers | Contact dirty | Clean with pencil eraser |
| App shows "---" | USB/Serial | Reconnect Arduino & select COM port |
