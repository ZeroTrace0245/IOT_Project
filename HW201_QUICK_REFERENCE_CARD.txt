## 🔒 SAFETY PATTERN

```
Before Motor Start:
  1. OBSTACLE_CHECK
  2. If OBSTACLE_STATE=0: Block motor
  3. If OBSTACLE_STATE=1: Allow motor

While Running:
  1. Monitor OBSTACLE_CHECK every 100ms
  2. If OBSTACLE_STATE=0: Send MOTOR_STOP
  3. Resume when OBSTACLE_STATE=1

Emergency Stop:
  MOTOR_STOP (immediate)
```
