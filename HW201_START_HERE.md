## 💻 THE COMMAND

```
New Arduino Command: OBSTACLE_CHECK
═══════════════════════════════════════

Syntax:
  OBSTACLE_CHECK

Response:
  [HW201] Obstacle sensor: CLEAR
  OBSTACLE_STATE=1

  OR

  [HW201] Obstacle sensor: OBSTACLE DETECTED!
  OBSTACLE_STATE=0

States:
  • 1 = No obstacle (path clear)
  • 0 = Obstacle detected (blocked)

Response Time:  <100ms (typical)
Use From:       Serial monitor or WinUI
Update Rate:    1Hz (auto) or on-demand
```
