## 🚀 QUICK START (2 MINUTES)

### Step 1: Upload Arduino Sketch
```
1. Open: Arduino/ComprehensiveArduinoControl.ino
2. Compile & Upload to Arduino Uno
3. Open Serial Monitor (9600 baud)
4. Type: HELP
→ See all available commands
```

### Step 2: Open WinUI App
```
1. Build & Run the app
2. Navigate to: "Arduino Control" tab
3. Verify connected COM port
4. Click "PING" to test connection
5. Use buttons to control hardware
```

### Example: Run Motor
```
1. Move slider to 128 (50% speed)
2. Click "Apply"
3. Motor starts at half speed
4. Click "Forward" or "Reverse"
5. Click "STOP" to stop immediately
```

## 🎮 30+ AVAILABLE COMMANDS

### MOTOR CONTROL (5 commands)
  MOTOR_SPEED=0-255      Set PWM speed
  MOTOR_DIR=0|1          Forward/Reverse  
  MOTOR_ENABLE=0|1       Enable/Disable
  MOTOR_STOP             Emergency stop

### STEPPER MOTOR (3 commands)
  STEP_PULSE=count       Send pulses
  STEP_SPEED=Hz          Set frequency
  HOME                   Move to limit

### SENSOR READING (4 commands)
  LIMIT_CHECK            Read limit switch
  PRESSURE_READ          Read I2C sensor
  ANALOG_READ=pin        Read A0-A5
  DIGITAL_READ=pin       Read any pin

### GPIO CONTROL (2 commands)
  DIGITAL_WRITE=pin,val  Set HIGH/LOW
  PWM_WRITE=pin,val      Set PWM 0-255

### SYSTEM COMMANDS (10+ commands)
  STATUS                 Show all values
  GET_STATE              JSON state
  SENSOR_SCAN            Find I2C devices
  UPTIME                 System runtime
  RESET                  Reset system
  HELP                   Show commands
  PING                   Echo test
  ... and more

## 🔌 PIN CONFIGURATION

DEDICATED PINS:
  Pin 2: Motor direction control (DIR)
  Pin 3: Stepper motor pulses (STEP)
  Pin 4: Limit switch input (INPUT_PULLUP)
  Pin 5: Motor driver enable (EN)
  Pin 8: Motor speed PWM (PWM)

AVAILABLE PINS:
  Digital I/O: 0, 1, 6, 7, 9, 10, 11, 12, 13
  Analog Input: A0, A1, A2, A3, A4, A5
  PWM Output: 3, 5, 6, 9, 10, 11
  I2C Bus: A4 (SDA), A5 (SCL)

  // Read all sensors

  2. Click "Read" (Pressure)
  3. Click "Read" (Analog, select pin)

  // Control LED on Pin 7
  1. Select pin 7
  2. Select HIGH
  3. Click "Write Digital"
  4. LED turns on
  5. Repeat with LOW to turn off

EXAMPLE 5: PWM Brightness
  // Dim LED via PWM (Pin 6)
  1. Set PWM pin to 6
  2. Set value to 100 (40% brightness)
  3. Click "Write PWM"
  4. Adjust value for brightness
