┌──────────────────────────────────────────────────────────────────────────────┐
│                    🔧 IF SOMETHING FAILS - QUICK FIXES                       │
└──────────────────────────────────────────────────────────────────────────────┘

No LED Light
└─ Check: Power (12V), GND, 100µF capacitor

Motor Won't Move
└─ Check: STEP pin (Pin 3), EN pin low, motor coils

Motor Only Vibrates
└─ Fix: Swap RED↔BLUE or BLACK↔GREEN motor wires

Limit Switch Fails
└─ Check: Pin 2, switch wiring, pullup

Pressure Sensor Stuck
└─ Check: A0 pin, sensor power/ground

No Serial Output
└─ Check: COM port, 9600 baud, USB cable

→ FULL SOLUTIONS IN: DRIVER_TESTING_GUIDE.md

┌──────────────────────────────────────────────────────────────────────────────┐
│                        💡 PRO TIPS FOR SUCCESS                               │
└──────────────────────────────────────────────────────────────────────────────┘

1. ⭐ Start with the guides - Don't skip them
2. 🔌 Check wiring first - 90% of issues are wiring
3. 🔋 Verify 100µF capacitor - Without it, driver won't work
4. 🐛 Use QuickDriverTest - For live component debugging
5. 📸 Take photos - Compare with wiring guides
6. 🔄 Swap motor coils - If motor only vibrates
7. 📊 Watch Serial Monitor - Most info is displayed there
8. ⚙️ Use 9600 baud - Not 115200 (ESP32 uses that)
