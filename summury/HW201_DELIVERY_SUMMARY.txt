## 💻 New Command

### `OBSTACLE_CHECK`

**Reads HW201 infrared obstacle sensor**

```
Command:  OBSTACLE_CHECK
Response: [HW201] Obstacle sensor: CLEAR
		  OBSTACLE_STATE=1

OR

Response: [HW201] Obstacle sensor: OBSTACLE DETECTED!
		  OBSTACLE_STATE=0
```

**States**:
- `1` = CLEAR (no obstacle)
- `0` = OBSTACLE DETECTED

### Example 1: Basic Obstacle Detection
```
// Via WinUI
Click "Arduino Control" → "Sensor Reading" → "Read" (HW201)
Display: CLEAR or OBSTACLE DETECTED

// Via Serial
Send:    OBSTACLE_CHECK
Display: OBSTACLE_STATE=1 (clear) or 0 (obstacle)
```

### Example 2: Collision Avoidance
```
// Safe motor operation
1. Check obstacle:     OBSTACLE_CHECK
2. If clear (1):
   - Enable motor:    MOTOR_ENABLE=1
   - Set speed:       MOTOR_SPEED=150
   - Start moving
3. Monitor:            OBSTACLE_CHECK (continuous)
4. If blocked (0):
   - Stop motor:      MOTOR_STOP
   - Wait for clear
```

### Example 3: Get Complete System State
```
Command:  GET_STATE

  "motorDir":1,
  "motorEnabled":false,
  "limitTriggered":false,
  "obstacleDetected":false,
  "pressure":512,
  "uptime":3600
}
```

## 📞 Support

### Troubleshooting

**Sensor not detecting obstacles?**
- Check Pin 6 connection
- Verify 5V power
- Ensure detection range (2-40cm)

**Always showing "OBSTACLE DETECTED"?**
- Move objects away from sensor
- Check for sunlight interference
- Clean sensor lens

**WinUI not updating?**
- Rebuild application
- Check serial connection
- Verify COM port selected
