# 🔍 SENSOR DETECTION SYSTEM - QUICK REFERENCE

## What It Does

Automatically detects and validates all connected sensors at system startup.

```
STARTUP SEQUENCE:
1. Initialize GPIO + I2C
2. Send handshake to each sensor
3. Collect responses
4. Report connection status
5. Continuous monitoring
```

---

## Sensor ID Reference

| Sensor | ID | Pin/Address | Type | Status |
|--------|-----|-----------|------|--------|
| Limit Switch | 0x01 | Pin 4 | Digital | ✓ Digital Input |
| Motor PWM | 0x02 | Pin 8 | PWM | ✓ PWM Output |
| Stepper Motor | 0x03 | Pin 3 | Digital | ✓ Digital Output |
| Humidity (DHT22) | 0x04 | Serial | Serial | ✓ Serial Protocol |
| Pressure Sensor | 0x05 | 0x76 | I2C | ✓ I2C Bus |

## Detection Method by Type

### Digital Sensors (GPIO)
```
1. Send HIGH pulse
2. Wait for response
3. Read pin state
4. Validate signature
```

### I2C Sensors
```
1. Start I2C transmission
2. Send to device address
3. Check acknowledgment
4. Record address
```

### Analog Sensors
```
1. Write test value
2. Wait for feedback
3. Read response
4. Check range
```

## Troubleshooting

| Problem | Cause | Fix |
|---------|-------|-----|
| All sensors not detected | Not connected to Arduino | Connect via USB & select COM port |
| Some sensors missing | Bad wiring | Check all connections |
| Hangs/times out | Sensor not powered | Check power supply |
| I2C not found | Bus issue | Check pull-up resistors (4.7kΩ) |
| Inconsistent detection | Electrical noise | Add capacitors near sensors |
