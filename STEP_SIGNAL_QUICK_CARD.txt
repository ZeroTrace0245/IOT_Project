## WHAT IS A STEP SIGNAL?

```
A short pulse (2 microseconds) that tells the stepper driver:
"Move the motor ONE STEP"

Each step = 1.8° rotation (200-step motor)
50 steps = 90° (quarter turn)
100 steps = 180° (half turn)
200 steps = 360° (full turn)
```

## STEP COUNT CALCULATOR

```
For 200-step stepper motors:
1.8° per step

90° turn:   90 ÷ 1.8 = 50 steps
45° turn:   45 ÷ 1.8 = 25 steps
30° turn:   30 ÷ 1.8 = 17 steps
180° turn:  180 ÷ 1.8 = 100 steps
360° turn:  360 ÷ 1.8 = 200 steps
```

---

## SPEED REFERENCE

```
Delay Between Pulses:

1ms   → ~1000 steps/sec  (Very Fast)
5ms   → ~200 steps/sec   (Fast)
10ms  → ~100 steps/sec   (Normal)
50ms  → ~20 steps/sec    (Slow)
100ms → ~10 steps/sec    (Very Slow)
```

## TROUBLESHOOTING IN 30 SECONDS

| Issue | Check | Fix |
|-------|-------|-----|
| No motion | Wiring, power | Verify connections, check driver power |
| Skipped steps | Too fast | Slow down, increase delay |
| Inconsistent | Timing issue | Reduce speed, check pulse width |
| Wrong direction | DIR pin polarity | Swap direction signal |
| No serial data | COM port | Select correct port in app |
